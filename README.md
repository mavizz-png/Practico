# Biblioteca Digital — Práctico 2

## Instalación (XAMPP)
1. Copiar la carpeta a `C:\xampp\htdocs\biblioteca`.
2. Iniciar Apache y MySQL en XAMPP.
3. Importar `sql/biblioteca.sql` desde phpMyAdmin.
4. Abrir `http://localhost/biblioteca/crear_admin.php` (una vez) y luego borrar ese archivo.
5. Abrir `http://localhost/biblioteca/`.

Admin de prueba: `admin@biblioteca.com` / `admin123`

## Documentación
Ver carpeta `docs/` (MER, pasaje a tablas, glosario de datos).
